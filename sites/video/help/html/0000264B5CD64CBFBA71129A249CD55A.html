Скрыть/показать оглавление 

Инструмент позволяет включить показ древовидного содержания книги для быстрой навигации по ее разделам и главам или отключить его, чтобы максимальное количество информации поместилось на экран.

Сложность

Для выбора уровня сложности главы или раздела в выпадающем списке выберите от 3 до 5. При выборе сложности 3  отображаются главы со сложностью 3. При выборе 4 отобразятся главы со сложностью 3 и 4. При выборе 5 – главы с любым уровнем сложности (3, 4, 5).

Поиск

Для поиска по тексту книги введите в поле Поиск искомое слов или фразу. Названия глав в дереве содержания окрасятся в тёмно-красный цвет, а в области Содержание раздела искомое слово или фраза подсветится оранжевым цветом

Ночной режим

Ночной режим используется для удобства чтения в темноте. Кроме того, при темном экране устройство потребляет меньше энергии. Чтобы включить ночной режим, установите флажок в области переключения режима , фон книги станет черным, а текст – белым. Для возврата в обычный режим нужно снять флажок в области переключения режима.

Заметки

При работе с электронным учебником существует возможность создавать заметки, к которым удобно оперативно возвращаться для закрепления материала или использования в процессе обучения.

Создание заметок

Для создания заметки:

1. Выделите текст в области «Содержание главы» и выберите на панели инструментов Заметки / Добавить.

2. В диалоговом окне ввести текст заметки и нажать кнопку Создать.

Важно! Можно создавать несколько заметок к одной странице или главе курса.

Навигация по заметкам

После создания заметки выделенный текст для нее будет подсвечиваться серым цветом, при наведении на него курсора появится всплывающее окно, содержащие текст заметки. Кроме того, глава, содержащая заметки, в содержании будет обозначена пиктограммой  

Перемещаться по сделанным заметкам можно двумя способами:

1 способ: Переход к заметкам в содержании учебника.

2 способ: Переход к заметкам через окно всех заметок. Для просмотра всех сделанных заметок выберите на панели инструментов Заметки / Просмотреть все. Откроется окно с перечнем всех сделанных заметок. Чтобы перейти к интересующей заметке достаточно просто нажать на нее.

Удаление заметок 

Чтобы удалить заметку:

1. Выберите на панели инструментов Заметки / Просмотреть все.

2. В открывшемся окне нажмите кнопку удаления в строке с удаляемой заметкой.

3. Подтвердите удаление заметки.

Экспорт и импорт заметок

Для сохранения и использования в дальнейшем заметки можно экспортировать и импортировать.

Чтобы экспортировать заметку, выберите на панели инструментов Заметки / Экспортировать, укажите место сохранения заметок и нажмите ОК.

Чтобы импортировать заметку, выберите на панели инструментов Заметки / Импортировать, в окне выбора файла укажите файл с экспортированными заметками (в формате xml) и нажмите ОК.

Закладка

При работе с электронным учебником существует возможность создавать закладки, которые удобно использовать для оперативного перехода к нужной главе или подразделу электронного учебника.

Создание закладки

Чтобы создать закладку:

1. Выберите нужную главу или подраздел в области содержание.

2. Выберите на панели инструментов Закладка / Добавить.  

В содержании перед названием главы-подраздела появится символ ·.  

Важно! Можно создавать несколько закладок.

Просмотр всех закладок

Для просмотра всех сделанных закладок выберите в панели инструментов Закладки / Просмотреть все.  

Откроется окно с перечнем всех сделанных закладок. Чтобы перейти к интересующей закладке достаточно просто нажать на нее.

Удаление закладок

Чтобы удалить закладку:

1. Выберите в содержании книги главу–раздел, в котором установлена закладка.

2. Выберите на панели инструментов Закладка / Удалить.

3. Подтвердите удаление закладки.

Чтобы удалить все закладки, выберите Закладки / Удалить все и подтвердите удаление.

Озвучить

При необходимости обучающийся может воспользоваться инструментом озвучки, который позволяет преобразовать текст в голос.

Для прослушивания текста выделите фрагмент текста, который нужно прослушать, и выберите на панели инструментов Озвучить.

Чтобы остановить воспроизведение, перейдите на другую главу или щелкните мышью внутри главы.

Глоссарий

Чтобы просмотреть глоссарий электронного учебника (список терминов, требующих комментариев и пояснений), нажмите на панели инструментов кнопку Глоссарий.

Запись на консультацию

Работая с электронным учебником, обучающийся может записаться на консультацию к преподавателю.

Для записи на консультацию к преподавателю на панели инструментов нажмите кнопку Запись на консультацию, выберите преподавателя из списка. Отобразятся контактные данные преподавателя, по которым вы сможете записаться на консультацию.
