Кнопки управления

  •  

Кнопки управления можно использовать для перехода между главами и разделами (Рис. 1.3). Для открытия нужной страницы введите номер страницы и нажмите кнопку На страницу. 

Кнопки управления

Если кнопка Предыдущая страница нажата на первой странице, происходит переход к последней странице предыдущей главы (если текущая глава не первая). По нажатию кнопки Следующая страница осуществляется переход с последней страницы главы на первую страницу следующей главы (если текущая глава не последняя).
