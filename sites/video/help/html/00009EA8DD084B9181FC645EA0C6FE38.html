Запуск тестов

  •  

Тесты входного контроля запускаются автоматически при запуске ЭОК.

Тесты рубежного контроля, итогового контроля, мотивационного блока запускаются по ссылкам.

После перехода к тесту будет предложено выбрать уровень сложности или вернуться к изучению теории:

По нажатию кнопки Начать тестирование откроется окно тестирования, в котором будут указаны:

  • Тема теста;
  • Номер вопроса;
  • Количество верных ответов;
  • Время до завершения теста или время для ответа на текущий вопрос (Если время для ответа на вопрос истекает, происходит автоматический переход к следующему вопросу. Возврат на вопрос с истекшим временем невозможен);
  • Вопрос;
  • Варианты ответов или поле для ввода ответов.

При необходимости выполнить расчеты, пользователь может воспользоваться калькулятором. Для запуска калькулятора на панели инструментов нажмите кнопку Калькулятор .
