Здесь должны располагаться html-файлы справки.

Файлы справки должны генерироваться отдельной выгрузкой в html книги со справкой.
Полученные в результате html-выгрузки файлы необходимо скопировать в каталог help.
После этого содержимое каталога help должно выглядеть следующим образом:

\help\html\*.html
     \media\*.*
     index.html
